Personal Portfolio Website
Project Description

This project is a personal portfolio website designed using HTML, CSS. It showcases a web developer and designer's introduction, services, and contact information through a modern and attractive design.

Features
Responsive portfolio homepage
Navigation bar with Home, About, Services, and Contact
Login and Register buttons
Personal introduction section
Hire Me button
Attractive background image
Modern dark-themed design
Technologies Used
HTML5
CSS3
